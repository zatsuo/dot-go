# 塗る

ドット絵の上をペンで塗ると、その色が体の面に貼りつく。向き・ポーズ・体型を変えても、塗った所についてくる。
服の細部 (えり・ボタン・柄)、顔、1 画素単位の直しは、これで描く。作りは `core/Paint.cs`。

## 使い方

左の「塗る」タブを開いているあいだ、真ん中の絵の上は「つまむ」ではなく「塗る」になる。

- 左ボタン = 塗る、右ボタン = 消す、Alt + クリック = 絵から色を拾う
- 太さ 1〜8 画素。「左右対称に塗る」で体の反対側にも
- 「光に合わせて影をつける」: 入れると、服と同じ決まりで色の段がつく (明るい所・暗い所で色が変わる。線の下)。
  切ると、塗った色そのまま (線よりも上)。目・口は切る
- 向きは ← → キーか上のボタン、または右の「横から」の絵をつまんで回す
- Ctrl+Z で戻せる。`.dotg.json` に保存される。PNG・シートにも出る

## 仕組み

- 絵を描くとき、画素ごとに「その画素に写っている体の場所 (基本姿勢での位置)」を残している (`GBuffer.Rest`)
- 塗った 1 画素 = 「点」1 つ。体の上の場所 + 大きさ + 色。絵を描くたびに、画素ごとに その場所がどの点の中にあるかを調べる。
  あとから塗った点が勝つ。消しゴムも点
- 点の場所と大きさは「いちばん近い骨の枠の中で、骨の長さ・太さで割った値」で持つ。体を作り直したら、
  新しい骨から場所を出し直して、面の上に寄せる。頭身や服の厚みを変えても残り、体の部分といっしょに伸び縮みする
- 点が 1 画素より小さくなっても消えない (半径の下限 0.55 画素)

## 確かめ

```
Godot --headless --path . -s tools/paint_shot.gd -- shots/paint.png
    正面で目と胸の線を塗り、向き 5 つ × (立ち・走り・すわる・2 頭身・6 頭身) を並べる。目の画素の数も出す
```

結果 (2026-11-11): 正面で塗った目 4 画素 → ななめでも 4、走りで 3〜5、2 頭身で 6 (頭が大きくなったぶん)、6 頭身で 4。

## できないこと・苦手なこと

- 体から離れた形 (フリル・広がるすそ) は作れない。面の色を変えるだけ
- 見えている面にしか塗れない。後ろは回して塗る
- 向きを変えると、1 画素の点は 0〜2 画素にゆれる (ななめから見た 1 画素の線は、とぎれることがある)
- 外の線 (シルエットの外に足した 1 画素) の上には塗れない (そこには体が無い)
- 服を脱がせると、服の上に塗った点は その下の肌に移る
- penInk には まだ渡らない

## 明るさのペン (2026-11-12)

「ペンの種類」で 色 / 明るく / もっと明るく / 暗く / もっと暗く を選ぶ。明るさのペンは色を置かずに、
その場所の色の段を 1 段 (もっと = 2 段) 上げ下げする (`DotCore.PaintKind`、点の種類 Light / Dark / Strong / Tone)。

- 髪でも肌でも服でも、下の素材の段の色になる。色の塗りの上に重ねても色は残る (色とは別の層)
- いちばん明るい段より上は、白へ寄せた色を作る (少し黄み)。いちばん暗い段より下は、少し青みへ暗く (`Pixel.Shift`)
- 消しゴム (右ボタン) は、色も明るさも消す
- 髪のつやの帯も同じ仕組み (+1 段)。塗った所・明るさを変えた所には出さない
- 作り直しのとき、もう面のそば (0.75 ます以内) にある点は寄せ直さない。髪の式は本当の距離ではないので、
  寄せ直すと かえって動き、作り直すたびに髪の上の塗りがずれた (16 画素 → 2 画素)。まだ 2 画素ほどは動くことがある

確かめ: `tools/tone_shot.gd`
