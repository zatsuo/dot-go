# 体型の数値とその根拠

## 骨の置き方 (全部の頭身で同じ式)

low-Godough の `core/rig.py` と同じ (元は Godough の docs/PROPORTIONS.md: Drillis & Contini の実測比、美術解剖の頭身、アニメの崩し方)。
身長 H と頭身から頭の高さ h = H / 頭身。あごから下の長さ B = H − h。目印は B に対する比で置く。

- 肩の高さ = B × (1 − 首の長さ)、股 = B × 脚の長さ、ひざ = 股 × 0.607、足首 = 股 × 0.083
- 胴 T = 肩 − 股。股関節 = 股 + 0.175T、くびれ = 股 + 0.425T、あばらの下 = 股 + 0.6T
- 上腕 0.535T、前腕 0.42T、手 0.155T + 0.062B

だから 6 頭身のひな形は low-Godough の「アニメ 少女 (6 頭身)」と同じ骨になる。

どこから来た数値か:

- **6・7.5・8 頭身**: low-Godough のひな形 (アニメ 少女 / リアル / 理想・ヒーロー) そのまま。
- **5・4 頭身**: low-Godough の「子ども」「デフォルメ」が元。首だけ長くした (下の「首」)。
- **3・2.5・2 頭身**: **資料から取った数値ではない**。調べて分かったのは向きだけ:
  - ドット絵の RPG のキャラは実際の人の比率を保たず、頭がスプライトの大部分を占め、手足は太く短い
  - 2 頭身は「胴の丸の半分で上下を分ける」(Godough docs/PROPORTIONS.md 3 章) → 脚の長さ 0.40
  - 頭身が下がるほど頭は丸く (幅 0.81h → 0.95h)
  頭身ごとの具体的な比率の表は見つからなかった。そこで、上の向きに沿って置いた値を、
  `tools/shot.gd` で 5 方向の絵を出して見ながら直した。直した理由は下。

## 絵を見て直したこと

- **肩幅が low-Godough のままだと、腕が胴に埋まる** (2 頭身)。胴を太くすると胴の横の面が肩の関節より外に出るため。
  肩の関節が胴の横の面のすぐ外に来るまで肩幅を広げた (2 頭身で 2.45 倍)。
- **筋肉のふくらみ (お尻・下腹・僧帽筋・太もも・ふくらはぎ) は、ちびでは無くす** (`morph: "detail"`)。
  小さい絵では、でこぼこは斑点や余計な線になる。胸も 8 割へらす。
- **胴の厚み** を幅とは別に持つ (`depth`)。幅だけ太くすると、横から見て板になる。
- **下ろした腕の開き** はちびほど大きく (2 頭身で 30°、4.5 頭身以上で 12°。`poses.gd` の `hang_for`)。丸い胴に腕が埋まらないように。
- **足** は大きめ (2 頭身で 1.5 倍)。小さい絵で足が 1 画素になると立って見えない。

## ユーザーに言われて決めたこと (2026-11-10)

- **首は欲しい** → ちびでも首の長さを 0 にしない (2 頭身で 0.075。頭と肩のあいだに 1〜2 画素あく)
- **ちびの体はもう少しふっくら** → 太さ 1.5 前後。ただし **丸すぎない** → おなかの出っぱり (`belly`) はほぼ 1、
  胴の厚み 1.55 まで。玉ではなく、ゆるい台形の胴
- **ちびの頭が四角っぽい・エイリアンっぽい** → 頭の輪郭を作り直した (`Sdf.cs` の ChibiFrontHalf / ChibiSide):
  - 四角く見えた原因: 上から見た輪切りの丸みの指数が 2.3 (2 より大きいと角が立つ) → 2.08
  - エイリアンに見えた原因: いちばん広い所が高く (頭の高さの 0.56)、あごへ細くすぼまっていた
    → いちばん広い所を 0.53 に下げ、ほっぺた (0.18〜0.3) をふくらませ、あごの先をとがらせない

## 肩の盛り上がり (2026-11-11)

ユーザー: 「肩の盛り上がりは解消したい」(2 頭身・上着の後ろ姿で、肩の端が首のつけ根より高く角になっていた)。

- 測り方: `tools/shot.gd` の `probe=1`。首のつけ根から外へ、面のいちばん上の高さを並べる (単位は あごから下の長さ B)
- 原因は服ではなく体: **肩の丸み (三角筋の玉)** の大きさは腕の太さで決まる。ちびは腕が短くて太いので、玉が上腕より長くなり、
  腕のつけ根より上へはみ出していた。2 頭身で、首と肩のあいだの谷より 0.036 B 高い (220 画素の絵で 4 画素)
- 直し: ちびに近いほど 玉を小さく (`morph: "ball"`、ちびで半分)、腕のつけ根を下げる (ちびで 0.035 B。なで肩)。
  2 頭身の盛り上がりは 0.036 → 0.010 B。4 頭身以上は変えていない
- 服の上の端は えりぐりの形で切る (docs/CLOTHES.md)
