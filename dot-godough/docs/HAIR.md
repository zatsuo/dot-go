# 髪

作りは `core/Sdf.cs` の `Hair`。ひな形と数値は `scripts/main.gd` の `HAIRS` / `HAIR_UI`。

## 調べたこと・引きついだこと

- ドット絵の髪は、束を 1 本ずつではなく少ないかたまりで描く。色は 2〜3 段
  ([PixelJoint](https://pixeljoint.com/forum/forum_posts.asp?TID=19203))
- 髪は 前髪・サイド・後ろ髪 に分けて考える。輪郭を頭にぴったり沿わせるとヘルメットに見える
  ([CLIP STUDIO](https://www.clipstudio.net/oekaki/archives/168993)、[同](https://www.clipstudio.net/oekaki/archives/160962))
- low-Godough の決まり (low-godough/docs/HAIR.md): 頭より少し大きい土台、いちばん張り出した所から下はまっすぐ垂れる、
  シンプルな髪型はシンプルに (ボブ = 前髪 1 枚 + 後ろ髪 1 枚)

## 形

髪 = 「頭を厚みだけふくらませた殻」を、下の端で切ったもの。体と同じ 1 枚の面に入るので、頭から浮かない・すき間があかない。

- 頭のいちばん広い高さより下は、その高さの輪切りのまま、まっすぐ下へ垂れる
- 下の端と厚みは、頭のまわりの向き (0° = 正面、180° = 後ろ) で 3 つに分ける:
  前髪 (正面 ± 前髪の幅)、横 (そこから 約 105° まで)、後ろ
- 長さの目盛り: 0 = 頭のてっぺん、1 = あご、2 = くびれ、3 = ひざ、4 = 地面。
  あごから下を体の目印で測るので、同じ「ロング」が 2 頭身でも 6 頭身でも同じ所 (くびれの少し上) まで届く
- 毛先のギザギザ: 下の端を、向きに沿った三角の波で上下させる (24° ごと)
- 毛先の内巻き: 下の端の手前から内へすぼめる。0 だと箱に見える
- あごより下は、下へ行くほど細くする (そのままだと頭の幅の板になる)
- つやの帯: 光の計算ではなく、頭のまわりの決まった高さの画素を 1 段明るくする (こちらを向いている面だけ)

## ペンで描く (2026-11-11)

ユーザーの方針: 「可能な限り自由な表現ができるツールに」「描画と一緒な感覚で描けるといい。つまむ、は直感的でないかも」。
だから 絵を描くのと同じ操作にする: **左ボタン = 髪を描く、右ボタン = 消しゴム、Ctrl+Z = 1 筆もどす**。部品を選ぶ・つまむ操作は作らない。

「髪」タブを開いているあいだ、絵 (真ん中・「横から」) の上で塗った所が、ボタンを離すと立体の髪になる (`DotCore.HairStroke`)。

- 太さは画素 (塗った幅 = 髪の幅)。引いている最中は、塗られる画素をそのまま見せる
- 描いた線 = 線に沿ったカプセルの列 (房)。「抜き」を上げると線の終わりが細くなる
- 奥行き: 線が頭や髪の上を通る所は その面の上 (半分ほど埋める)。面から外へ出た先は、最後に通った面の奥行きのまま。
  頭に 1 度も触れない線は、頭の真ん中を通る 絵と平行な面の上
- 消しゴム = 線の形を、描いたときの見る向きへ奥に押し抜いた形で髪を消す (保存では半径が負、最後に [向き, 奥行き])。
  消した画素からは髪が見えなくなる。押し抜くのは頭の高さの半分まで: 前髪を消しても、頭の向こうの後ろ髪は残る。
  はじめは線のまわりだけ浅く削る形にしたが、太い房を細い消しゴムでなぞっても溝ができるだけで、絵の上では消えなかった
- 分け目 = 前髪を下から上へ消す (逆 V 字)。ななめの前髪・片目隠し・房を途中で切る、も消しゴム
- 描く・消すは描いた順に効く (消したあとに描いた髪は消えない)
- 1 点だけ (クリック) なら玉 = おだんご。「左右対称に描く」でツインテール
- 房の点は頭の枠で持つ (÷ 頭の大きさ)。頭身を変えると頭といっしょに伸び縮みする。ひな形を変えても残る
- 描いた髪は ひな形の髪と ひとかたまり (同じ部品 15)。束ごとに線が出るのは変、とユーザーから (2026-11-12)。
  線が出るのは、体のほかの所と同じく 奥行きの差が大きい重なりだけ。「描いた髪を線で分ける」を入れたときだけ 房を部品 16 にする
- 描いた所は必ず見える: 体や頭の面より奥へは置かない (胸の前に垂らした線が、体の中に隠れていた)
- 消しゴムは、髪に触れない線なら何もしない (線も足さない・元に戻す の 1 回ぶんも使わない)
- つやの帯は、描いた髪には出さない (ツインテールやおだんごを横切る縞になる)
- 房は下へ垂れていても頭についていく (殻の、あごより下が胸についていく決まりは使わない)
- ひな形「なし」のまま、ペンだけで髪を作ることもできる
- 保存は `hair.locks`

確かめ: `tools/hairpen_shot.gd` (ツインテール・アホ毛・横から描いたポニーテール・おだんご・分け目・ななめ前髪・房を切る)、
`tools/hairpen_feel.gd` (塗った画素のうち髪になった割合。2026-11-12: 太さ 1 = 88%、2〜4 = 95〜99%、胸の前 = 86%、消しゴムのあと 0%)

## 動き

- あごより上は頭についていく。あごより下へ垂れた分は、下へ行くほど胸についていく (首を回しても背中の髪は背中に残る)
- 腕のめり込み直しは、髪を相手にしない (長い髪を腕がよけると、腕が真横に開いた)。髪には腕が重なってよい

## まだ無いもの・苦手なこと

- 頭のてっぺんの分け目の「線」は形では出ない (切ると肌が見える)。線は「塗る」で描く
- 描いている最中は平らな色の下書きで、立体になるのはボタンを離してから (0.3〜0.4 秒)。筆圧は使っていない
- 房は丸い断面だけ (平たい束・リボンのような形は作れない)。色は髪ぜんぶで 1 色
- 髪のゆれ。長い髪は、胸の向きに板のようについていく
- つやの帯は、光が当たっていちばん明るい段になっている所では見えない (それより上の段が無い)
- 前髪は顔の上にかぶるので、「塗る」で描いた目が前髪の下に隠れることがある

確かめ: `tools/shot.gd` に `hair=ボブ` (数値の上書きは `h_bangs=0.5` のように)
