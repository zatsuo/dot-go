# お手本に画素単位で似せる

似せたいドット絵 (スプライトの表でもよい) を開いて、絵の上に重ね、ちがう画素を数えながら寄せていく。
左の「お手本」タブと、絵の下のパレット、「塗る」タブの「この絵の画素」を使う。

## 流れ

1. 「お手本」タブ →「お手本の絵を開く…」。絵の中のキャラを**クリック** (つながっている 1 体を選ぶ)。
   キャラどうしがくっついている表は、**つまんで囲む**か、「ますの幅・高さ」を入れてクリック。
   背景が塗ってある絵は、左上の色を「何も無い」として扱う。
2. 「紙とキャラの大きさを お手本に合わせる」→ 紙 = お手本 + 余白 2、キャラの高さ = お手本の高さ (外の線のぶん 2 引く)。
   お手本は、形がいちばん重なる所へ自動で置く (←→↑↓、または絵の上をつまんで動かせる)。
   頭身・体型・髪・服は、重ねた絵を見ながら今までのタブで合わせる。
3. 「色を お手本から取る」→ 肌・服・髪それぞれの 影・基本・明るい・線を、お手本の同じ場所でいちばん多い色にする。
   1 色ずつ直すのは「ドット絵」タブの「素材ごとの色」(左クリック = ペンの色を入れる、右クリック = その色を拾う)。
4. 残りは「塗る」タブで塗る先を「この絵の画素」にして 1 画素ずつ。
   「ちがう画素を全部 お手本の色に直す」で、いまの向きを お手本と同じにもできる。

絵の左上に「お手本と同じ 84% (380 / 451 画素)・形のちがい 23」と出る。
比べるのは、どちらかに何か描いてある画素。色は 8 ビットの値がぴったり同じなら「同じ」。

## 見せ方

かくす / すかして重ねる / ちがう画素を光らせる (赤紫 = 色がちがう、黄 = お手本にだけある、水色 = こちらにだけある) / お手本だけ見る。
R キー = お手本だけ ⇔ 元の見せ方。

## ペンの色とパレット (絵の下)

- 大きい四角 = ペンの色 (押すと色を作れる)。小さい四角 = もう 1 つの色 (X で入れかえ)
- パレット: 左クリック = ペンの色、右クリック = 外す。キー 1〜9・0 = 先頭の 10 色
- 「＋ 今の色」「お手本の色」(お手本に使われている色に入れかえ)「今の絵の色」「読む…」(.png / .hex / .gpl)
- 最近使った色 10 個 (右クリックでパレットに足す)
- Alt + 左 = 絵の色を拾う (何も無い所は お手本から)、Alt + 右 = お手本の色を拾う。[ ] = ペンの太さ

## ドット直し (この絵の画素)

できあがった絵の画素を、そのままの色に置きかえる。線の上・体の外にも置ける。「透明にする」で画素を消せる。右ボタン = 直しを取りのぞく。

- **ポーズごと・向きごと**に持つ (`pose.fix[向きの度数][紙の真ん中下からの場所] = 色`)。体の面の塗りとちがい、向きを変えるとついてこない
- 体・ポーズを変えても、直した画素はその場所に残る (形を先に決めてから使う)
- 紙の大きさを変えても、足もとの真ん中からの場所は保つ。見下ろす角度は区別しない
- PNG・シートの書き出しに入る。penInk には渡らない

## 素材ごとの色の段

服・髪はふだん「基本」の色から 影・明るい・線を作る (`ramp_of`)。お手本に合わせるときは 5 色を自分で決められる
(`garment.ramp` / `hair.ramp` = [濃い影, 影, 基本, 明るい, 線])。服・髪の色を選び直すと、自動に戻る。

## 中身

- `core.Classes()`: 最後に描いた絵の、画素ごとの「素材 × 8 + 段」(線 = 素材 × 8 + 7、無い = -1、塗り = -2)。色を取るのに使う
- main.gd: `load_ref` `ref_island` `set_ref_rect` `fit_paper_to_ref` `ref_align` `colors_from_ref` `ref_trace` `fix_line` `pick_color` `palette_*` `mat_get / mat_set`
- 保存: `ref` (絵の場所・範囲・ずれ)、`palette`、ポーズの `fix`、服・髪の `ramp`。お手本の絵そのものは入れない (場所だけ)
