# 服

服のメッシュは作らない。服 = 「体のどこからどこまでを、どれだけふくらませて、何色にするか」の並び。

## 種類

| 種類 | 中身 | 例 |
| --- | --- | --- |
| body | 胴と脚の、縦の範囲をふくらませる。`sleeve` を入れると そでつき | シャツ・ズボン・靴下・靴・上着 |
| arm | 腕の範囲だけ | 手袋 |
| skirt | 腰から下がる、だ円のすそ (体から離れる) | スカート・ワンピースやコートのすそ |

- 縦の目盛り: 0 あご・1 肩・2 くびれ・3 股・4 ひざ・5 足首・6 地面
- 腕の目盛り: 0 肩・1 ひじ・2 手首・3 指先
- 厚み・広がりは身長の 100 分の 1 が単位 (頭身を変えても同じ見え方になる)

目盛りが体の目印で決まっているので、同じ服が 2 頭身にも 8 頭身にも着せられる。

## めり込まない仕組み

| 起きそうなこと | どう防いでいるか |
| --- | --- |
| 肌が服を突き抜ける | 服は「体そのものを厚みだけ外へふくらませた形」(`Field.GarmentDist`)。体と服をまとめて 1 枚の面にするので、服の下の肌は面として存在しない。ポーズをつけても出てこない |
| 肩の上に、そでの布だけが残って盛り上がる | 肩より上から始まる服の上の端は、まっ平らに切らない。首のまわりだけその高さで切り、首から離れるほど高い所で切る (えりぐり。`Field.Top`)。そでも同じ線で切る |
| 重ね着で下の服が出てくる | 色は「その場所をおおっている、並びでいちばん後ろの服」で決める (`Field.Full`)。厚みの大小では決めない |
| 左右のズボンがくっついて 1 本になる | 脚の服は、真ん中にすき間 (`Field.Slit`) を残して切る |
| スカートから脚が出る (立ち) | すその広がりは、立ち姿の体 (下に着た服も) を 6 つの高さで測って、それより必ず外にする (`Body.MeasureSkirt`)。頼んだ広がりで足りなければ自動で足す |
| スカートから脚が出る (歩く・すわる) | すその点は腰についていき、下へ行くほどその側の太ももにもついていく (`Mesher`、「脚についていく」の数値) |
| 腕が胴・頭・服・スカートに沈む | 腕の点を、胸 (腰より下は腰) の骨といっしょに基本姿勢へ戻して、腕を除いた形までの距離を測る (`DotCore.ArmClearance`)。入っていたら、離れていく向きへ 2° ずつ上腕を回す (`FixArms`)。そでの布が胴の服に重なるのは、布の厚みの 8 割まで許す (許さないと、厚い上着で腕が開きすぎる) |

腕を直すのは、体や服を変えたとき・ひな形のポーズをあてはめたとき・「いま、腕のめり込みを直す」を押したとき。
自分でつまんで動かしている最中には、勝手に動かさない。

## 防いでいないこと

- 腕以外どうし (脚と脚、手と頭など) のめり込みは測っていない。ポーズをつける人が避ける
- ひねった胴・曲げた背中に対しては、腕の測り方が近似 (胸と腰の 2 つの骨で代表させている)
- ちびは腕が短いので、「ばんざい」は頭の横を持つ形になる (頭の中には入らない)

## 苦手なこと

- 細部 (ボタン・えり・柄): 形では出さない。顔と同じく、できた絵の上に描く仕組みを作る予定
- ひらひらした動き: すそが太ももについていくところまで
- 前が開いた上着
