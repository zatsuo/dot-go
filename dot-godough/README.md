# dot-Godough

SDF で作った人体を、その場でドット絵にして見ながら、体型とポーズを決める道具。
low-Godough の体の作り方 (骨に貼りついた肉を SDF でなめらかにつなぐ) を移して、
2 頭身のドット絵キャラから low-Godough の既定 (6 頭身) やリアル頭身まで、頭身のスライダー 1 本で行き来できるようにした。

- 起動: `Run.bat` (C# をビルドしてから Godot 4.6 .NET で開く)
- 保存: `.dotg.json` (体型・画風・ポーズの一覧)
- 書き出し: PNG 1 枚 / ポーズ × 4・8 方向のシート (PNG + 並びの JSON) / penInk 用のキャラのフォルダ

## 画面

| 場所 | 中身 |
| --- | --- |
| 左「体型」 | 頭身のひな形 (2〜7.5)、体型のスライダー。動かすとすぐドット絵が変わる。開いているあいだは、絵の上で輪郭をつまんで形を変えられる (下) |
| 左「服」 | ひな形 (シャツ・ズボン・スカート・靴…) を足して、範囲・厚み・色を変える。docs/CLOTHES.md |
| 左「ドット絵」 | 絵の大きさ、肌の色の段、光、線、画素の決め方、ふちの濃い色 (試作) |
| 左「ポーズ」 | ポーズの一覧、ひな形のポーズ、左右の入れかえ、選んだ関節の角度 |
| 左「塗る」 | 開いているあいだ、真ん中の絵の上をペンで塗れる。色は体に貼りつく。docs/PAINT.md |
| 左「髪」 | ひな形 (ショート・ボブ・ロング)、色、長さ・厚み・毛先。docs/HAIR.md |
| 左「お手本」 | 似せたいドット絵を重ねて、ちがう画素を数える。色を取る・画素をじかに直す。docs/REFERENCE.md |
| 左「立体」 | ドット絵から作った立体: ポーズ (手・足の先をつまむ)、部品の塗り分け、アニメーション、GIF・Aseprite の書き出し。docs/SOLID.md |
| 「お手本」の 4 | 正面のドット絵 1 枚から立体を作る試作。横・後ろに描き足すと立体が変わる。docs/SOLID.md |
| 絵の下 | ペンの色とパレット (1〜0 キー、Alt + クリックで色を拾う) |
| 真ん中 | ドット絵そのもの。関節の点をつまんで動かす。右どなりに、90° 横から見た絵 (奥行きを見る・つまむ) |
| 右「見え方」 | 等倍・2 倍・3 倍、8 方向 |
| 右「penInk」 | 同じ体・ポーズ・向きを penInk に描かせた絵、penInk Animator で開く |
| 右「3D」 | 網目そのもの (色は部品ごと) |

ポーズのつけ方 (真ん中の絵の上で):

- 点をつまんで動かす。手首・足首は、ひじ・ひざがついてくる (2 本まとめて動く)
- 腰の大きい点 = 体ごと動かす。足は地面に残るので、下げるとしゃがみ、横へ動かすと片足に乗る
- 脚を動かしても足の裏の向きは変わらない。「左右いっしょに動かす」で反対側も鏡写しに動く
- 腕が胴や服に入ったら自動で開く (体や服を変えたとき・ひな形のポーズをあてはめたとき)
- 点の上でホイール = ひねる (Shift で 15° ずつ)。右クリック = その関節をもどす
- 奥行き (手前・奥): 右どなりの「横から」の絵で点をつまむ。横から見ると左右の点が重なるが、
  真ん中の絵で先に選んだ点があれば、そちらをつまめる
- Shift を押しながら上下 = 奥行きだけ動かす (下 = 手前、上 = 奥)
- Alt を押しながら = 奥行きを反対側へ (手前に出すか、奥へ引くか)
- 何もない所を左右につまむ = 向きを回す。← → キーで 45° ずつ
- Ctrl+Z / Ctrl+Y = ポーズの元に戻す・やり直す

輪郭をつまむ (「体型」タブを開いているあいだ。ポーズの点は出ない):

- 体をつまんで、骨に直角に動かす = その部品の太さ (つまんだ所がマウスについてくる)。骨に沿って動かす = 長さ
- 腕 = 腕の太さ・長さ、手 = 手の大きさ、脚 = 脚の太さ・長さ、足 = 足の大きさ、頭 = 頭の幅・頭身、
  胴 = 高さで 肩幅・おなか・腰幅、スカート = すその広がり
- 右の「横から」の絵でつまむと、前後の向き (胴の厚み・頭の奥行き)
- 動くのは体型のスライダーと同じ数値。左右の腕・脚は いっしょに変わる (片方だけ・1 か所だけ、はまだできない)
- 何もない所を左右につまむと向きが回る。Ctrl+Z で体型ごと戻る

## 作り

```
core/Sdf.cs      形の組み合わせ (SDF)・三面図の頭。low-Godough の core/sdf.py・head.py と同じ式
core/Rig.cs      骨と肉。頭身ごとの体型の表 (Rig.Curve)。数値の根拠は docs/PROPORTIONS.md
core/Mesher.cs   SDF → 網目 (surface nets)。重みと部品の番号も SDF から
core/Raster.cs   ポーズをつけて (スキニング)、画素ごとの情報に撮る (自前。GPU は使わない)
core/Pixel.cs    画素ごとの情報 → ドット絵 (色の段・線)。決まりは docs/LOOK.md
core/Sdf.cs の Garment / core/Rig.cs の AddGarments  服 (体をふくらませる・すそ)
core/Paint.cs    塗り (体の面に貼りつく点)
core/Gltf.cs     penInk 用のフォルダ (gltf + bin + cel.json) を書く
core/DotCore.cs  画面 (GDScript) から呼ぶ窓口
scripts/main.gd  画面とポーズの操作      scripts/poses.gd  ひな形のポーズ
scripts/penink.gd  penInk の描画サーバー (penInk/tools/animator_server.py) を起こして絵をもらう
```

網目は人が編集するものではなく、ドット絵に撮るためのもの。1 枚の閉じた網目で、法線は SDF の勾配から取るので、
面の粗さは絵に出ない。体を作り直すのに 50〜250 ミリ秒、絵を 1 枚描くのに数ミリ秒。

## 確かめ

```
Godot --headless --path . -s tools/shot.gd -- shots/a.png px=64 heads=2,3,6 yaws=0,45,90,180 pose=立ち wear=長そでシャツ,ズボン,靴 hair=ボブ
    頭身 × 向きの表を PNG に (画面なし)。網目の穴の数・左右のずれも出す。
    probe=1 で、肩の上の輪郭 (首のつけ根から外へ下がり続けているか) を数値で出す
Godot --headless --path . -s tools/export_penink.gd -- <フォルダ> <名前> heads=3
Godot --headless --path . -s tools/hairpen_shot.gd -- shots/hairpen.png
    ペンで引いた線が髪の房になるかの表
Godot --headless --path . -s tools/paint_shot.gd -- shots/paint.png
    塗りが向き・ポーズ・頭身についてくるかの表
Run.bat -- --selftest <フォルダ>
    画面を開いて一通り操作し、画面の絵・書き出し・log.txt を残す
```

## まだ無いもの

- 顔: 3D の顔の部品は作らない。できあがったドット絵の上に描く (ただし向きやポーズについてくるように) 方針。
  目印にするため、画素ごとに「体のどこか (基本姿勢での位置)」を残してある (GBuffer.Rest)
- 頭から離れる髪 (ツインテールなど)・髪のゆれ。服の細部 (ボタン・えり・柄) は「塗る」で描く。顔も同じ仕組みで描けるが、顔のための道具 (目のひな形など) はまだ
- ふちの濃い色: いま入っているのは仮 (シルエットの内側を 1 段暗く)。くわしい説明を聞いてから作り直す
- 動き (コマ送り)

## アニメーションは別アプリ

上の列「モデルを書き出す」で `.dotmodel.json` を作り、となりのフォルダ dot-godough-motion (dot-Godough モーション) で開く。向こうの `scripts/solid.gd` などは ここの写し (向こうの `Sync.bat` で写す)。
