# dot-Godough モーション

dot-godough で作った ドット絵モデルに 動きをつけて、Aseprite・GIF・シートに書き出すアプリ (Godot 4.6、GDScript だけ)。

- 起動: `Run.bat`
- 確かめ: `Run.bat -- --selftest <出力のフォルダ>` (tests/selftest.gd)

## 流れ

1. dot-godough の上の列「モデルを書き出す」で `キャラ.dotmodel.json` を作る (キャラのファイル `.dotg.json` も そのまま開ける)
2. このアプリの「モデルを開く」で開く。あとで モデルを作り直したら、もう一度「モデルを開く」— アニメは残って モデルだけ入れかわる
3. アニメを作る → 「保存」(`.dotanim.json`。モデルも中に入る) → 書き出す

## 8 方向の歩きスプライト

右の「歩き (8 方向)」: 「歩き」という名前のアニメを 8 方向で シート PNG (行 = 向き、列 = コマ + `.json`)・Aseprite (向きごとにタグ)・GIF に書き出す。
「歩き」のアニメが無ければ、立体の歩き 4 コマで作って足してから書き出す。

## 考え方

- アニメ = 名前・長さ (コマ)・速さ (コマ/秒)・くり返す・キー
- キー = そのコマのポーズ。キーの無いコマは、前のキーのまま (ドット絵ふうの コマ送り)。「キーのあいだを混ぜる」を入れると 前後を なめらかに混ぜる
- 絵は コマごとに立体から描く (`scripts/solid.gd`)。つまんで動かすと そのコマにキーが打たれる

## 操作

| | |
|---|---|
| 色のついた丸をつまむ | 手・足の先 = 腕・脚ごと (Shift で先だけ)、ほか = その部品を回す |
| 右クリック (丸) | その部品を まっすぐに戻す |
| 何もない所を引く | 向きを回す (はなすと 45° にそろう) |
| ← → ↑ ↓ | 全体を 1 画素動かす |
| Space / , . | 再生 / コマ送り |
| K / Delete | キーを打つ / 消す |
| Ctrl+C / Ctrl+V / Ctrl+Shift+V | ポーズを写す / 貼る / 左右を入れかえて貼る |
| Q E | 向きを 45° ずつ |
| Ctrl+Z / Ctrl+Y / Ctrl+S | 元に戻す / やり直す / 保存 |

## 紙の大きさ

ポーズが紙から はみ出すと切れる。左の「紙の大きさ (余白を足す)」で 左右 (同じだけ)・上・下に余白を足す。
「はみ出さない大きさにする」= 全部のアニメ・全部のコマ・8 方向を調べて、切れない いちばん小さい余白 (上と左右) にする。
キーは そのまま。書き出す絵も この大きさになる。もとのモデルは変えない (`DotSolid.padded`)。

## 書き出し

- Aseprite (`.aseprite`): 等倍・レイヤー 1 枚。「このアニメ・この向き」「このアニメ・8 方向」「全部のアニメ・8 方向」。アニメ × 向きごとにタグ (例: 「歩き 左」)。コマの長さは アニメごとの速さ
- GIF: この向き / 8 方向を 4 × 2 に並べる
- シート PNG: 行 = 8 方向、列 = コマ。となりに `.json`
- ぐるっと一周 (GIF / Aseprite): いまのコマのポーズを 8〜48 方向で順に。「回りながら アニメも進める」も選べる

## dot-godough と同じファイル

`scripts/solid.gd`・`anim_export.gd`・`pixel_view.gd`・`xp.gd` は dot-godough の写し。向こうを直したら `Sync.bat` で写す (となりのフォルダ `..\dot-godough` から)。

## まだ無いもの

- コマごとの ドット直し (描いて直す)。直しは Aseprite でする前提
- キーを引いて動かす・何コマも選ぶ
